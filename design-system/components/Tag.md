# Tag

Small uppercase labels that sit above an event title.

- **Category** (`brand` fill, `on-brand` text): one per event. "LIVE MUSIC", "FOOD & DRINK", "NIGHTLIFE".
- **Status** (transparent, 1px white border at 70%): time or urgency. "TONIGHT", "FREE", "SELLING FAST".
- **Date badge** on Saved tiles uses the category style with the date ("FRI 3 OCT").

Use the `tag` text style, uppercase, padding 5px 8px and `radius-tag`. Two tags maximum per event.
