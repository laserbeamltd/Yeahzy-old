# Chip

Toggleable pills for picking interests and filtering lists.

- **Interest chip** (`chip-height`, padding 0 18px, 16px text): unselected is `surface-200` with white 500 text; selected is `brand` with `on-brand` 700 text. Use `aria-pressed`.
- **Filter chip** (40px high, 14px text): the same states at a smaller size, used on Saved ("Upcoming", "This week", "Free").

Chips wrap with an `space-8`–10px gap. Selection is shown by fill, never by colour of text alone.
