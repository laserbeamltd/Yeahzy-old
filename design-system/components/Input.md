# Input

Text fields for sign up, log in and search, with the label always visible above.

- Field: `input-height`, `surface-100` fill, `radius-md`, 16px 500 white text, placeholder at 45% white.
- Label: `meta` style in 75% white, `space-8` above the field.
- Focus: 1px `brand` border.
- Password fields carry a 44px show/hide eye button inside the right edge.
- Verification code: six 64px boxes in a grid with `space-8` gaps, digits in the display face; the active box gets a 2px `brand` border.
